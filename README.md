# OrganizaTudo - Trabalho de SI

Trabalho prático feito por **Kayk** e **Itamar** para a faculdade de Sistemas de Informação.

## O que é o projeto?
A gente criou um site bem simples de lista de tarefas (tipo um bloco de notas inteligente) para ajudar a organizar as coisas do dia a dia. Ele funciona como uma página única (SPA), ou seja, dá para adicionar e apagar as tarefas na mesma tela sem precisar ficar recarregando a página.

## O que a gente usou?
* **React** com **Vite**: Escolhemos porque o professor pediu um framework moderno e esse foi o mais fácil da gente aprender e organizar em partes (componentes).
* **JavaScript, HTML e CSS básico**: Para fazer a lógica e a parte visual da tela.

## O que o sistema faz (Requisitos)
* Tela simples e organizada.
* Formulário para cadastrar a tarefa.
* Validação para não deixar salvar tarefa sem título.
* Dá para ver a lista de tarefas cadastradas.
* Botão para excluir a tarefa que já terminou.
